# 🎨 ASCII Image Converter (Web Version with Pretext)

Современное веб-приложение для конвертации изображений в ASCII-арт с использованием **Pretext** для точного рендеринга текста.

## ✨ Возможности

- 🖼️ **Drag & Drop** — перетаскивайте изображения прямо в браузер
- 🎭 **3 стиля**: Classic, Heart ❤️, Deadinside ZXC
- 🎛️ **Настройки**: ширина, глитч-эффект
- 📋 **Копирование** в буфер обмена одним кликом
- 💾 **Экспорт** в `.txt` или `.html`
- 🚀 **Pretext** для идеального layout и измерения ASCII-текста
- 📱 **Адаптивный дизайн** — работает на всех устройствах

## 🚀 Запуск

Просто откройте `index.html` в браузере! Никаких зависимостей и установок.

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

## 🛠️ Технологии

- **HTML5 Canvas API** — обработка изображений
- **Pretext** (@chenglou/pretext) — точный text layout
- **Vanilla JavaScript** — без фреймворков, максимальная скорость
- **Modern CSS3** — градиенты, анимации, адаптивность

## 📖 Как использовать

1. Откройте `index.html` в браузере
2. Загрузите изображение (drag & drop или клик)
3. Выберите стиль и настройки
4. Нажмите "Конвертировать"
5. Скопируйте или скачайте результат!

## 🎨 Стили

- **Classic** — классический ASCII-арт с рамкой из `#`
- **Heart** — романтичный стиль с `<3` и розовыми оттенками
- **Deadinside** — тёмный стиль с `zxc` и глитч-эффектами

## 🆚 Отличия от Python-версии

| Возможность | Python (Tkinter) | Web (Pretext) |
|-------------|------------------|---------------|
| GUI | Tkinter | Modern HTML/CSS |
| Обработка | PIL/Pillow | Canvas API |
| Рендеринг текста | Моноширинный шрифт | Pretext (точный layout) |
| Установка | Требуется Python | Работает в браузере |
| Мобильная версия | ❌ | ✅ |
