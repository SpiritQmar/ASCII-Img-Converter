# ASCII Image Converter (Web Version with Pretext)

- **HTML5 Canvas API** — обработка изображений
- **Pretext** (@chenglou/pretext) — точный text layout
- **Vanilla JavaScript** — без фреймворков, максимальная скорость
- **Modern CSS3** — градиенты, анимации, адаптивность


## Стили

- **Classic** — классический ASCII-арт с рамкой из `#`
- **Heart** — романтичный стиль с `<3` и розовыми оттенками
- **Deadinside** — тёмный стиль с `zxc` и глитч-эффектами
